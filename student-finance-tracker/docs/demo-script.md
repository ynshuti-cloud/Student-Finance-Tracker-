# M7 — 2–3 minute demo video script

Record your screen with your own voice or narration. Aim for about 2 minutes and 30 seconds.

## 0:00–0:20 — Introduce the project
“Hi, this is Campus Wallet, a student finance tracker I built using HTML, CSS and JavaScript. It helps students record income and expenses, check their balance and keep track of weekly spending.”

## 0:20–0:50 — Add and validate a transaction
“Here is the transaction form. I can choose income or expense, enter an amount, description, category and date. I will add a sample expense. The dashboard updates after saving. The form also checks the input, so a zero or negative amount will not be accepted.”

Show one successful transaction and one invalid amount.

## 0:50–1:20 — Dashboard and budget
“The top cards show my balance, total income, total expenses and transaction count. The weekly limit section shows how much of my spending limit I have used. If spending gets close to the limit, a warning appears. The category chart gives a quick view of where money is going.”

Set a low limit briefly if needed to show the warning.

## 1:20–1:50 — Search, sort, edit and delete
“I can search with normal words or a regular expression such as `/food|transport/i`. Matching words are highlighted. I can also filter by transaction type, sort the list, edit a record or delete it.”

Demonstrate search and one row action.

## 1:50–2:15 — Data and settings
“Transactions are saved in local storage, so they remain after refresh in the same browser. I can export a JSON backup or import a valid JSON file. The settings let me change the currency label and choose compact spacing.”

Show export, then settings. Explain that the currency label does not perform real conversion.

## 2:15–2:30 — Testing and finish
“I also included a test page for validation, search and calculations, plus sample data and a README with setup and testing instructions. Thank you for watching.”

Open `tests.html` and show the result count.

## Before submitting
- Use the final running version, not a code editor only.
- Ensure your name is visible if your course requires it, but do not show private data.
- Make the browser text large enough to read.
- Check the recording is 2–3 minutes and the audio is understandable.
- Upload the video where your instructor asked and include the link in your submission.
